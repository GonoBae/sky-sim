# 개발 일정

기준일: 2026-09-08

예정 기간: 2026-08-31 ~ 2026-11-20

1인 개발·Unreal Engine 5.6 기준의 12주 베타 계획이다.
목표는 에디터에서 하늘을 설정하고, 비행 중에도 시간·날씨·구름이 연속적으로 보이는 시스템이다.
현재 구현과 검사 결과는 [구현 현황](implementation-status.md)에 따로 기록한다.

날짜는 기존 계획을 유지한다. 목표 GPU·해상도·성능 기준과 최종 시연일은 아직 확정하지 않았다.

## 우선순위

| 우선순위 | 범위 |
|---|---|
| P0 | 구름 움직임·분포·고고도 경계, 시간·날씨 전환, 에디터 설정과 안정성 |
| P1 | 조명·그림자, 강수·번개·지면 반응, 성능 최적화 |
| P2 | 전용 렌더러, GPU solver, 관측·예보 연동과 다중 물리 영역 |

P0가 지연되면 P1 효과 범위를 줄인다.

## 현재 작업

| ID | 상태 | 남은 작업 |
|---|---|---|
| P0-01 구름 움직임 | 보간·평균 바람 적분·밀도 안정화 1차 구현, 자동화 통과 | 화면 이동 속도·잔상 측정, voxel별 velocity와 고도별 바람 보정 |
| P0-02 시간·빛 | 기본 수정 완료(9/4) | 부하별 시계 오차, 에디터 기준 캡처와 Fog 정책 점검 |
| P0-03 구름 분포 | 미해결 | 고정 군집·lobe 구조를 바꾸고 간격·높이·두께·생애주기를 다양화 |
| P0-04 고고도 경계 | 미해결 | 사각형 볼륨 밖으로 이어지는 중·원거리 구름과 전환 구현 |

다음 순서로 진행한다.

1. P0-01의 실제 화면 이동·잔상·밀도 포화를 날씨별로 확인한다.
2. P0-03의 가변 군집·형상 생성과 P0-04의 근·중거리 전환을 구현한다.
3. 행성 곡률을 따르는 원거리 표현을 연결해 고고도에서 보이는 경계를 없앤다.
4. voxel별 속도 보간, 에디터 설정, 조명·날씨 효과를 보강한다.

## P0 완료 기준

수치는 목표 기준이다. 아직 측정하지 않은 항목은 통과로 보지 않는다.

- P0-01: 60fps에서 입력 프레임 사이의 정지·급격한 교체가 없어야 한다. 기본 밀도와
  광역·세부 노이즈의 이동 방향이 같고 목표 속도 오차는 10% 이내, 풍속 변경·위상 순환 시
  위치 도약은 0.1 voxel 미만이어야 한다.
- P0-02: 날짜·배속에 맞춰 실제 시각과 태양광이 바뀌고, UTC 정지·재개와 서버 중단·재시작
  후 시각이 연속적으로 이어져야 한다. 현재 정지는 달력 시계 기준이다. 유체와 진행 중인
  날씨 전환까지 모두 멈추는 정책은 별도다.
- P0-03: 군집 수·간격·크기·고도·두께·lobe 구조가 seed와 생애주기에 따라 달라져야 한다.
  20km 간격의 자기상관 peak가 두드러지지 않고, 서로 다른 20km 영역의 정규화 상관계수
  중앙값은 우선 0.25 이하를 목표로 한다.
- P0-04: 고도 2·5·10·15·20km의 하향·사선 시점에서 사각형 외곽, 직선 잘림과 빈 고리가
  없어야 한다. 근·중·원거리 전환의 optical depth·색 차이는 5% 이내, 고도 15km에서
  약 500km 반경의 지평선 구름 연결을 목표로 한다.

랜덤 배치는 구름을 균일하게 흩뿌리는 방식이 아니다. 전선·바람 방향의 띠·대류 군집처럼
서로 연관된 구조를 유지하면서 군집 규모와 개별 형상을 다르게 만든다.

## 광역 구름 설계안

아래 구조는 계획이며 현재 구현이 아니다. 현재는 20km 기준 밀도장을 기본 120km 폭으로
반복·변형해 표시한다. 카메라를 따라 이동시키는 것만으로 고고도 경계는 없어지지 않는다.

| 영역 | 잠정 범위 | 역할 |
|---|---|---|
| Near 3D field | 항공기 중심 0~40km | 구름 내부 비행과 가까운 형상. 외곽 5~10km에서 감쇠 |
| Mid clipmap | 약 30~200km | Near와 겹치는 원형 영역. 거리별 해상도를 낮추며 밀도 인계 |
| Far planetary shell | 약 200~600km 이상 | 곡률을 따르는 구름층으로 지평선 연결 |
| Regional weather field | 약 256~1,024km 단위 | 구름 종류·양·고도, 전선 방향과 강수 분포 결정 |

Near 외곽을 지우기 전에 같은 위치에 Mid 구름이 있어야 한다. 5~10km 겹침 구간에서 밀도,
조명과 그림자를 함께 전환해 빈 고리나 색 차이가 남지 않도록 한다.

영역 중심은 항공기를 따라 이동하되 구름의 전역 좌표와 누적 이동량은 유지한다.
`weather seed + global tile ID + simulation time`으로 재생성하고 world-origin 변경 전후에도
같은 구름이 같은 위치에 남는지 확인한다.

## 검증 조건

매주 금요일 같은 장면·카메라·seed로 비교 캡처와 성능 기록을 남기는 계획이다.

- 날씨: Clear, Cumulus, Overcast, Rain, Storm, Snow, Fog, Natural.
- 시간·거리: 정오·일출·일몰·야간, 구름 내부와 1·10·50km 거리.
- 고고도: 2·5·10·15·20km에서 수직 하향, 30°·60° 사선과 지평선 방향.
- 경계: 축·대각선의 사각형 외곽, 직선 잘림, 빈 고리, 조명·그림자 이음새.
- 조작·안정성: 에디터·PIE, 배속·UTC 정지·역방향 시간, 서버 실행 순서·재시작·패킷 손실.
- 기록: 비교 이미지, CPU/GPU frame time, UDP 누락과 밀도 통계.
- 후속 장거리 검사: 300m/s·60분, 1,000m/s·10분, world-origin 재설정.

## 베타 완료 기준

1. 에디터와 Play에서 시간·위치·날씨·구름·조명 설정 결과가 일치한다.
2. 고도 2~20km에서 반복 패턴·사각형 경계·빈 고리가 보이지 않고 지평선 구름이 이어진다.
3. 시간·날씨 전환이 연속적이고 프리셋별 결과가 구별된다.
4. 재연결·서버 재시작·패킷 손실·시간 역행 후 정상 상태로 복구한다.
5. 2시간 실행에서 충돌, 지속적 메모리 증가와 복구 불가능한 렌더링 정지가 없다.
6. 합의한 Low/Medium/High 품질별 성능 기준을 만족한다.
7. 새 환경에서 문서만으로 빌드와 서버·Unreal 연결을 재현한다.

## 범위와 미정 사항

관측·예보 자료 동화, 다중 물리 영역, GPU solver와 완전한 전용 RDG 렌더러는 베타 범위에서
제외한다. TrueSky·Ultra Dynamic Sky의 전체 기능 동등성이나 모든 GPU·플랫폼 지원도
이번 완료 조건이 아니다.

Heterogeneous Volume으로 3주차 품질 기준을 맞추지 못하면 전용 렌더러 기술 검증을
앞당기고 강수·번개 등 P1 범위를 뒤로 조정한다.

확정할 항목:

- 목표 GPU·해상도·최소 FPS와 품질별 성능 예산.
- 실제 개발 인원, 최종 마감일과 외부 시연일.
- 비행 속도·고도·세션 길이·요구 가시거리.
- 평면·World Partition·구형 지구 등 좌표계와 월드 구조.
- 지원 Unreal 버전·플랫폼, 베타에 필요한 강수·번개·지면 효과 범위.
